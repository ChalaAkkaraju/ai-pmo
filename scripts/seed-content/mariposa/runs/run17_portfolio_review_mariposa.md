## 3. Cross-cutting risk taxonomy

Northwood's portfolio risk review uses six cross-cutting risk classes. The taxonomy is closed; classification outside the six is either project-specific or warrants a PMO Director decision on extending the taxonomy.

- **Vendor / supplier concentration.** Single-vendor or single-supplier dependencies where performance failure cascades to project outcome. Portfolio-relevant when multiple projects depend on overlapping vendor pools or when vendor-class behaviour (sole-source pricing, financial-health volatility, capacity constraints, accelerated-cadence pressure) recurs across projects.
- **Regulatory / external deadline.** Regulator-imposed schedule constraints — permit expiry, standard effective dates, tax-credit deadlines, court-ordered consent decrees, utility-driven energisation windows. Portfolio-relevant when regulator class appears across multiple projects or when deadline-driven pressure is a consistent pattern.
- **Site-conditions variance.** Site-specific discoveries during construction — geotechnical surprises, latent defects, environmental contamination, hidden infrastructure. Portfolio-relevant when project class (brownfield, variable-terrain greenfield, urban) recurs.
- **Resource / labour scarcity.** Local labour market, skilled-trade availability, accommodation, transport access. Portfolio-relevant when project class (rural location, regional construction boom, specialised-trade-dependent) recurs.
- **Client-driven scope or sequence changes.** Client-initiated mid-execution changes. Portfolio-relevant when contract structure (fixed-price vs T&M) interacts with client class (IPP, municipal, industrial owner-operator) in patterns that erode margin or compress schedule.
- **Weather / climate-sensitive construction.** Seasonal, climatic, or weather-event windows. Portfolio-relevant when project class (outdoor renewables, marine, indoor industrial) and geography produce recurring patterns.

The taxonomy is closed. A risk that does not fit any class is either project-specific (not portfolio-relevant) or warrants a new class — the latter is a PMO Director decision, not an analyst call. The candidate pattern in §2 item 4 (tax-credit-deadline pre-contract confirmation discipline gap) sits inside the existing Regulatory / external deadline class as a discipline-gap subcategory but is flagged here for PMO Director judgement on whether it warrants its own class.

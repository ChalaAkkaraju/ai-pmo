# Work Breakdown Structure (WBS) — Mariposa Wind Farm Phase 1

## 1. Project context

- **Project:** Mariposa Wind Farm Phase 1 (NW-REN-2511)
- **Client:** Mariposa Renewables Holdings (IPP)
- **Contract:** Fixed-price, $148.0M; approved budget $134.0M; contingency $5.5M
- **Northwood PM:** J. Okafor
- **WBS baseline date:** Week 0 (charter approval / contract signature 22 May)

## 2. WBS structure

Deliverable-oriented decomposition per PMBOK §5.4 (Create WBS). Decomposition uses the 100% Rule — every element of project scope is captured at exactly one place in the hierarchy. Numbering follows the standard outline convention. Note: no Demolition branch — this is a greenfield project per charter §2.

## 4. WBS conventions used

1. **Deliverable-oriented, not activity-oriented.** Each work package names what is produced. "Turbine foundations — 80 positions" (deliverable: 80 completed foundations) rather than "build foundations" (activity). PMBOK 100% Rule: every deliverable is captured at exactly one place.

2. **Three levels of decomposition by default; deeper where risk or coordination demands.** Level 1 (project) → Level 2 (phase/branch) → Level 3 (work package). No Level-4 decomposition is used at this draft stage; the energisation week and the OEM PO are the candidate points for Level-4 decomposition once schedule and procurement detail firm up.

3. **WBS dictionary required for non-trivial work packages.** Owner, deliverables, dependencies, risk linkage. Eight entries provided here covering camp facilities, OEM PO, subcontract packages, rural road upgrades, foundations, component logistics, grid energisation, and the performance test.

4. **Hedging discipline at the package level.** Inline italic annotations using `[NEEDS PM REVIEW: ...]` mark unresolved owners, dates, and decisions. Used per-package; not applied section-wide.

5. **Risk register cross-reference where applicable.** Work packages that exist because of a specific charter §8 risk carry a `Risk linkage:` clause in their dictionary entry. R1 (OEM concentration) maps to 3.1 and 3.11; R2 (tax-credit deadline) maps to 9.2; R3 (migratory bird blackouts) constrains 5.2 sequencing; R4 (rural roads) maps to the whole 4.0 branch; R5 (labour / camp) maps to 1.8 and 3.12.

## 5. Notes for downstream agents

- **Schedule Reasoner.** The critical path runs through 3.1 (OEM PO release) → OEM manufacturing → 7.1 (component delivery, gated by 4.4 and 4.5 road upgrades) → 7.2–7.4 (erection) → 9.2 (grid energisation, no later than 30 Dec year+1). Pay particular attention to: branch 4.0 as a parallel critical-path strand with hard finish dates driven by first heavy-haul; migratory bird blackout windows constraining 5.2 sequencing (charter §10 Constraint 3); the 30 November year+1 Substantial Completion target sitting one month before the 30 December year+1 hard energisation deadline — that one-month buffer is the only float against the tax-credit constraint.

- **Budget Builder.** Largest cost concentrations are 3.1 (OEM turbines — likely the largest single line item), 5.4 (80 foundations), 7.2–7.4 (turbine erection), and 6.4 (substation equipment). Branch 1.0 (Project Management) and 1.8 (camp) are sustained-cost packages running across the full project duration. The $5.5M contingency should be allocated with reference to risk-linked packages — heaviest weight to packages tied to R1, R2, and R4. Camp build-vs-lease (1.8 / 3.12) is a material capex-vs-opex decision still open.

- **Risk Analyst.** Five charter §8 risks all have explicit work-package homes in this WBS. The two risks without a single dedicated package — R2 (tax-credit deadline) and R3 (bird blackouts) — are managed as schedule constraints across multiple packages rather than as a single work package; R2 collapses onto 9.2 at the end of the chain, and R3 constrains sequencing within 5.2 and possibly 7.2–7.3. Watch for new risks emerging at the OEM design interface (2.11) and at the two-county DOT interfaces (4.2 and 4.3) — these are coordination-heavy packages where additional risks typically surface during execution.
